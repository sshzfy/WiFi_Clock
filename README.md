根据B站梅花嵌入式 STM32F407 桌面天气时钟项目改进：
    1). 使用LittleFS文件系统和外部Flash(W25QXX)管理字库和图片以及部分运行数据，极大降低了对单片机自身Flash的占用。
    2). 白天用 2.4" SPI (可触控)彩屏显示时钟、日期、实况天气与室内温湿度；夜间自动切到 0.96" OLED 只显示时间，
    同时冻结周期任务、让 ESP32-C3 进入 Modem-sleep。其中昼夜切换通过光敏传感器实现。
    3). 时间基准是 **SNTP 校时 + TIM5 推算的软件时钟**，夜间改用 **DS1302 外部 RTC**，断网也能正常走时。
    DS1302 为解决开发板无 LSE 晶振增加，可根据开发板实际情况增减。
    4). 简单移植 LVGL 实现用户自定义 WiFi 和定位城市(目前只支持到英文)；
    城市定位使用(省+)市的拼音，仅输入城市名称可能会由于城市名拼音相同而导致定位错误，省+市更准确。
